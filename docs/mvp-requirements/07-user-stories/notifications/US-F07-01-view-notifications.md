# US-F07-01 – View notifications

## User Story

As an **Employee, Asset Manager, or Admin**,\
I want to **view notifications related to me**,\
so that **I do not miss important business changes**.

## Acceptance Criteria

- AC-US-F07-01-01: When opening the list, then the system displays only notifications for the current user.
- AC-US-F07-01-02: Then notifications are sorted with the newest first.
- AC-US-F07-01-03: Then each notification shows its title, content, time, and read status.
- AC-US-F07-01-04: Then the system displays the number of unread notifications.
- AC-US-F07-01-05: The system creates notifications for request, approval, issue, handover, and return events; the recipient is determined by the related user/permission and entity.

## Applicable Business Rules

`BR-NOT-02`, `BR-NOT-04`, `BR-NOT-05`.

## Related Functional Requirements

`FR-F07-01`, `FR-F07-02`, `FR-F07-05`.
